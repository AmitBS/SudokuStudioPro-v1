# Sudoku Studio Pro — Native Android (Kotlin + Jetpack Compose)

This is the pure native Android Kotlin version of **Sudoku Studio Pro**.
It does **NOT** use any web server, browser, or `localhost`. It runs 100% locally on the Android device's CPU.

---

## How to Build the APK in Android Studio (1 Click)

1. Open **Android Studio**.
2. Click **File > Open...** (or "Open Project" on the welcome screen).
3. Select this folder:
   `C:\Amit\AI\Mobile\Sudoku Studio Pro\android-native`
4. Wait for Gradle sync to complete (Android Studio will automatically configure JDK, SDK, and build tools).
5. In the top menu, click:
   **Build > Build Bundle(s) / APK(s) > Build APK(s)**
6. Once finished, a balloon notification will appear:
   `APK(s) generated successfully for module 'app'`
   Click **"locate"** to open the folder with **`app-debug.apk`**.
7. Transfer **`app-debug.apk`** to your Android 12 phone and install it!
